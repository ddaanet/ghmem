# ghmem Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `tools/ghmem` uv-managed Python harness, two custom
Claude Code agents with mechanically enforced no-GitHub guardrails, and the
`docs/design/` artifact scaffold that reify micro's GitHub decision history
into maintained topic docs — then prove the pipeline on the wrapindent
cluster (with distractors), calibrate the formula constants against the real
corpus, and hand off a documented backfill runbook.

**Architecture:** A 12-factor split. All deterministic work — fetch, store,
render, rank, ledger — lives in a typed, lint-clean Python CLI (`ghmem`).
Agents never touch the GitHub API (a PreToolUse hook denies it); they read
what `ghmem` commands emit from the local corpus and only judge: route one
item per invocation, or write one topic doc. An append-only JSONL ledger is
the system's source of truth; a regenerable SQLite corpus mirrors it for
querying. Topic close-out is a snapshot-token compare-and-set so late routes
are never silently discarded.

**Tech Stack:** Python ≥3.14, uv-managed project, click CLI, githubkit
(GraphQL, typed, built-in retry), sqlite3, pytest + pytest-mock, ruff
`select=["ALL"]`, mypy `strict` + `extra_checks`, docformatter, justfile
`green` recipe. Quality bar reference: `/Users/david/code/edify/`.

## Global Constraints

- **Edify quality bar.** `just green` (format → ruff → docformatter -c →
  mypy → pytest) must pass before every commit. ruff `select=["ALL"]` with
  the edify ignore list; mypy strict + extra_checks; all code fully
  type-annotated, all functions docstringed (pep257).
- **Lint-friction deviation rule:** ruff-ALL/mypy-strict will flag things
  this plan's code did not foresee. Fix the code, keep the behavior, note
  the delta in the commit message. Add a config ignore only when a rule
  fights the design (not the code), and say so in the commit message.
- **No agent calls the GitHub API.** Only the harness talks to GitHub
  (githubkit; token from `$GITHUB_TOKEN` or `gh auth token`). The agents'
  guardrail is mechanical: a PreToolUse hook denies gh/network commands.
- **Ledger is the source of truth.** `tools/ghmem/ledger.jsonl` is
  append-only, committed, and mirrored into SQLite on every run. The corpus
  `tools/ghmem/corpus.sqlite` is regenerable and **gitignored**. `uv.lock`
  is committed.
- **Deterministic tests never hit the network.** pytest + checked-in JSON
  fixtures (`tools/ghmem/tests/fixtures/`); injectable seams (`graphql_fn`,
  `runner`) replace githubkit/git. Tests use `tmp_path` and plain asserts.
- **Naming.** The artifact is `docs/design/INDEX.md` plus flat
  `docs/design/<topic>.md` files. The word "dossier" is banned — say
  "topic doc". Every INDEX.md line ends with the issue/PR numbers it rests
  on, e.g. `(#2374, #3107)`.
- **Standing is computed, never fetched.** Contributor standing (owner /
  maintainer / established contributor / newcomer) is derived from corpus
  data as of each comment's posting date. Fetch-time `author_association`
  is stored as a hint column and shown only on recently-updated items
  (≤ `RECENT_HINT_DAYS`, default 90 — tunable constant); it is NEVER
  authority. Agents read annotations, never infer standing.
- **Formula constants are provisional until calibrated.** Heat weights and
  standing thresholds ship marked `PROVISIONAL` in code comments and are
  derived properly in Task 7's recorded calibration analysis.
- **80-column hard-wrap for prose** in every `.md` file this plan creates
  or edits. Code and fixture JSON are exempt.
- **Work in the parent repo** `/Users/david/code/micro` on a branch `ghmem`
  cut from `main`. The `micro/` submodule is read-only (only its `git log`
  is consumed); never commit inside it.
- **Shell idiom:** run commands as
  `(cd /Users/david/code/micro/tools/ghmem && <cmd>)` — a bare `cd` trips
  the environment's cwd guard.
- **Commit style:** plain imperative subject, backticks around identifiers,
  no attribution trailers.
- **The eight harness commands** are `sync`, `show`, `heat`, `triage`,
  `route`, `status`, `topic`, `index` (spec Architecture §1). No others.
  `ghmem triage` yields the next untriaged item (heat order) as a complete
  packet — id plus its `show` rendering — recording a `dispatched` ledger
  event so concurrent calls hand out distinct items. It exits 0 in both
  cases: stdout carries the packet, or is empty when triage is complete
  (with `triage complete: 0 pending` on stderr). Non-zero exit codes are
  reserved for actual errors. One item per agent invocation.
- **INDEX.md is autogenerated, never agent-edited.** Topic docs carry YAML
  frontmatter with a `description:` — the hook-style index line, ending
  with its issue/PR citations. `ghmem index` regenerates
  `docs/design/INDEX.md` from all topic docs' frontmatter, alphabetically
  by topic name (stable diffs); successful `topic --synthesized` close-out
  regenerates it too.
- **Python ≥3.14, modern annotations.** `requires-python = ">=3.14"`; no
  `from __future__ import annotations`, no quoted forward references —
  3.14 annotation semantics make them unneeded and undesirable. `uv sync`
  provisions CPython 3.14 itself (downloads a toolchain; needs network
  once — run the first sync with the sandbox off, like the live-network
  validation task).
- **Sequencing gates:** the wrapindent ground-truth validation (Task 6)
  MUST pass before any backfill; the calibration analysis (Task 7) MUST
  land before the campaign is run. The plan's job ends at a verified,
  calibrated pipeline plus a documented runbook (Task 8); the campaign
  itself runs in later sessions.
- **GraphQL deviation rule:** live schema field names may differ from what
  Task 2 assumes. Tests inject fixtures, so adapt query/extraction to the
  real schema and note the delta in the commit message — do not
  restructure the plan. Anything bigger: stop and report.

```python
"""Append-only JSONL ledger — the system's source of truth."""

import datetime
import json
from pathlib import Path
from typing import Any

Event = dict[str, Any]
"""One ledger event, as parsed from a JSON line."""


def _now() -> str:
    """Return the current UTC time as an ISO-8601 string."""
    now = datetime.datetime.now(tz=datetime.UTC)
    return now.strftime("%Y-%m-%dT%H:%M:%SZ")


def read(path: Path) -> list[Event]:
    """Return all ledger events in file order; missing file yields []."""
    if not path.exists():
        return []
    events: list[Event] = []
    with path.open(encoding="utf-8") as fh:
        for raw in fh:
            line = raw.strip()
            if line:
                events.append(json.loads(line))
    return events


def append(path: Path, event: Event) -> None:
    """Append one event as a JSON line, injecting a ts if absent."""
    record = dict(event)
    record.setdefault("ts", _now())
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("a", encoding="utf-8") as fh:
        fh.write(json.dumps(record, ensure_ascii=False) + "\n")


def record_topic(path: Path, name: str) -> None:
    """Record the creation of a topic."""
    append(path, {"event": "topic", "name": name})


def record_route(path: Path, item: str, topic: str) -> None:
    """Record a routing verdict assigning an item to a topic."""
    append(path, {"event": "route", "item": item, "topic": topic})


def record_no_signal(path: Path, item: str) -> None:
    """Record a no-signal verdict for an item."""
    append(path, {"event": "route", "item": item, "verdict": "no-signal"})


def record_fetch_failed(path: Path, item: str) -> None:
    """Record a fetch failure for later retry."""
    append(path, {"event": "route", "item": item, "verdict": "fetch-failed"})


def record_synthesized(path: Path, topic: str) -> None:
    """Record that a topic's doc was synthesized (clears dirty)."""
    append(path, {"event": "synthesized", "topic": topic})


def record_dispatched(path: Path, item: str) -> None:
    """Record that an item was handed to a triage agent."""
    append(path, {"event": "dispatched", "item": item})


def record_requeue(path: Path) -> None:
    """Return all unresolved dispatches to the queue (crash recovery)."""
    append(path, {"event": "requeue"})
```

```python
"""Tests for the SQLite corpus and ledger mirror."""

import sqlite3
from pathlib import Path

import pytest

from ghmem import db


@pytest.fixture
def conn(tmp_path: Path) -> sqlite3.Connection:
    """Open a fresh corpus database."""
    return db.connect(tmp_path / "corpus.sqlite")


def seed_item(conn: sqlite3.Connection, item_id: str, **kw: object) -> None:
    """Insert a minimal item row, overridable via keyword arguments."""
    kind, _, num = item_id.partition("/")
    args: dict[str, object] = {
        "id": item_id, "number": int(num) if num.isdigit() else 0,
        "kind": kind, "title": "t", "state": "open", "author": "a",
        "body": "", "created_at": "2022-01-01T00:00:00Z",
        "updated_at": "2024-01-01T00:00:00Z", "reactions": 0, "raw": "",
    }
    args.update(kw)
    db.upsert_item(conn, **args)  # type: ignore[arg-type]


def test_upsert_item_and_comment(conn: sqlite3.Connection) -> None:
    """Items and comments insert and update idempotently on id."""
    seed_item(conn, "issue/2374", title="Line length option", reactions=5)
    db.upsert_comment(conn, id="c1", item_id="issue/2374", author="a",
                      body="hi", created_at="2023-01-01T00:00:00Z",
                      kind="comment")
    row = conn.execute(
        "SELECT title, reactions FROM items WHERE id='issue/2374'"
    ).fetchone()
    assert row["title"] == "Line length option"
    assert row["reactions"] == 5
    seed_item(conn, "issue/2374", title="Renamed", state="closed")
    row = conn.execute(
        "SELECT title, state FROM items WHERE id='issue/2374'").fetchone()
    assert row["title"] == "Renamed"
    assert row["state"] == "closed"


def test_merge_and_hint_fields(conn: sqlite3.Connection) -> None:
    """Merge fields and the author_association hint store and default."""
    seed_item(conn, "pr/2900", author="helper", merged_by="dmaluka",
              merged_at="2024-02-01T00:00:00Z", assoc_hint="CONTRIBUTOR")
    row = conn.execute(
        "SELECT merged_by, merged_at, assoc_hint FROM items "
        "WHERE id='pr/2900'").fetchone()
    assert row["merged_by"] == "dmaluka"
    assert row["merged_at"] == "2024-02-01T00:00:00Z"
    assert row["assoc_hint"] == "CONTRIBUTOR"
    seed_item(conn, "pr/2901")
    row = conn.execute(
        "SELECT merged_by, assoc_hint FROM items WHERE id='pr/2901'"
    ).fetchone()
    assert row["merged_by"] is None
    assert row["assoc_hint"] is None
    db.upsert_comment(conn, id="c2", item_id="pr/2900", author="x",
                      body="b", created_at="2024-01-15T00:00:00Z",
                      kind="comment", assoc_hint="MEMBER")
    row = conn.execute(
        "SELECT assoc_hint FROM comments WHERE id='c2'").fetchone()
    assert row["assoc_hint"] == "MEMBER"

    """Meta keys set, update, and read back; missing keys are None."""
    db.set_meta(conn, "cursor_issues", "CUR1")
    assert db.get_meta(conn, "cursor_issues") == "CUR1"
    assert db.get_meta(conn, "missing") is None


def test_rebuild_ledger_routes_and_dirty(conn: sqlite3.Connection) -> None:
    """Replay produces current routes and dirty topics."""
    events = [
        {"event": "topic", "name": "wrapindent"},
        {"event": "route", "item": "pr/3107", "topic": "wrapindent"},
        {"event": "route", "item": "issue/2374", "topic": "options"},

def test_rebuild_is_idempotent(conn: sqlite3.Connection) -> None:
    """Rebuilding twice from the same events changes nothing."""
    events = [{"event": "route", "item": "pr/1", "topic": "t"}]
```

```python
from pathlib import Path

from ghmem.ledger import Event

SCHEMA = """
CREATE TABLE IF NOT EXISTS items (
    id          TEXT PRIMARY KEY,
    number      INTEGER NOT NULL,
    kind        TEXT NOT NULL,
    title       TEXT NOT NULL,

    body        TEXT,

);

    name        TEXT PRIMARY KEY,
    created_at  TEXT
);

    seq         INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id     TEXT NOT NULL,
    topic       TEXT,
    verdict     TEXT NOT NULL,
    ts          TEXT
);
CREATE TABLE IF NOT EXISTS dirty (
    topic       TEXT PRIMARY KEY
);
CREATE TABLE IF NOT EXISTS dispatched (
    item_id     TEXT PRIMARY KEY,
    ts          TEXT
);
"""


def connect(path: Path) -> sqlite3.Connection:
    """Open (creating if needed) the corpus database at path."""
    path.parent.mkdir(parents=True, exist_ok=True)
    conn = sqlite3.connect(path)
    conn.row_factory = sqlite3.Row
    conn.executescript(SCHEMA)
    conn.commit()
    return conn


def upsert_item(  # noqa: PLR0913 -- mirrors the items schema
    conn: sqlite3.Connection,
    *,
    id: str,  # noqa: A002 -- domain name for the item key
    number: int,
    kind: str,
    title: str,
    state: str,
    author: str | None,
    body: str,
    created_at: str,
    updated_at: str,
    reactions: int,
    raw: str,
    merged_by: str | None = None,
    merged_at: str | None = None,
    assoc_hint: str | None = None,
) -> None:
    """Insert or update one item row keyed on id."""
    conn.execute(
        """INSERT INTO items
           (id, number, kind, title, state, author, body, created_at,
            updated_at, reactions, merged_by, merged_at, assoc_hint, raw)
           VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)
           ON CONFLICT(id) DO UPDATE SET
             number=excluded.number, kind=excluded.kind,
             title=excluded.title, state=excluded.state,
             author=excluded.author, body=excluded.body,
             created_at=excluded.created_at, updated_at=excluded.updated_at,
             reactions=excluded.reactions, merged_by=excluded.merged_by,
             merged_at=excluded.merged_at, assoc_hint=excluded.assoc_hint,
             raw=excluded.raw""",
        (id, number, kind, title, state, author, body, created_at,
         updated_at, reactions, merged_by, merged_at, assoc_hint, raw),
    )
    conn.commit()


def upsert_comment(  # noqa: PLR0913 -- mirrors the comments schema
    conn: sqlite3.Connection,
    *,
    id: str,  # noqa: A002 -- domain name for the comment key
    item_id: str,
    author: str | None,
    body: str,
    created_at: str,
    kind: str,
    assoc_hint: str | None = None,
) -> None:
    """Insert or update one comment row keyed on id."""
    conn.execute(
        """INSERT INTO comments
           (id, item_id, author, body, created_at, kind, assoc_hint)
           VALUES (?,?,?,?,?,?,?)
           ON CONFLICT(id) DO UPDATE SET
             item_id=excluded.item_id, author=excluded.author,
             body=excluded.body, created_at=excluded.created_at,
             kind=excluded.kind, assoc_hint=excluded.assoc_hint""",
        (id, item_id, author, body, created_at, kind, assoc_hint),
    )
    conn.commit()


def add_xref(conn: sqlite3.Connection, src_id: str, dst_id: str) -> None:
    """Record a cross-reference edge (idempotent)."""
    conn.execute(
        "INSERT OR IGNORE INTO xrefs (src_id, dst_id) VALUES (?,?)",
        (src_id, dst_id),
    )
    conn.commit()


def set_meta(conn: sqlite3.Connection, key: str, value: str) -> None:
    """Set a meta key (e.g. a sync cursor)."""
    conn.execute(
        "INSERT INTO meta (key, value) VALUES (?,?) "
        "ON CONFLICT(key) DO UPDATE SET value=excluded.value",
        (key, value),
    )
    conn.commit()


def get_meta(conn: sqlite3.Connection, key: str) -> str | None:
    """Read a meta key, or None when unset."""
    row = conn.execute(
        "SELECT value FROM meta WHERE key=?", (key,)).fetchone()
    return None if row is None else str(row["value"])


def rebuild_ledger(conn: sqlite3.Connection, events: list[Event]) -> None:
    """Wipe and replay the ledger-mirror tables from the event list."""
    conn.execute("DELETE FROM topics")
    conn.execute("DELETE FROM routes")
    conn.execute("DELETE FROM dirty")
    conn.execute("DELETE FROM dispatched")
    conn.execute("DELETE FROM sqlite_sequence WHERE name='routes'")
    dirty: set[str] = set()
    for event in events:
        name = event.get("event")
        ts = event.get("ts")
        if name == "topic":
            conn.execute(
                "INSERT OR IGNORE INTO topics (name, created_at) "
                "VALUES (?,?)", (event["name"], ts))
        elif name == "route":
            conn.execute("DELETE FROM dispatched WHERE item_id=?",
                         (str(event["item"]),))
            _replay_route(conn, event, ts, dirty)
        elif name == "synthesized":
            dirty.discard(str(event["topic"]))
        elif name == "dispatched":
            conn.execute(
                "INSERT OR IGNORE INTO dispatched (item_id, ts) "
                "VALUES (?,?)", (str(event["item"]), ts))
        elif name == "requeue":
            conn.execute("DELETE FROM dispatched")
    for topic in dirty:
        conn.execute(
            "INSERT OR IGNORE INTO dirty (topic) VALUES (?)", (topic,))
    conn.commit()


def _replay_route(
    conn: sqlite3.Connection,
    event: Event,
    ts: object,
    dirty: set[str],
) -> None:
    """Replay one route event into the mirror, updating dirty topics."""
    item = str(event["item"])
    topic = event.get("topic")
    verdict = event.get("verdict", "route" if topic else "no-signal")
    prev = conn.execute(
        "SELECT topic FROM routes WHERE item_id=? ORDER BY seq DESC LIMIT 1",
        (item,)).fetchone()
    conn.execute(
        "INSERT INTO routes (item_id, topic, verdict, ts) VALUES (?,?,?,?)",
        (item, topic, verdict, ts))
    if topic:
        conn.execute(
            "INSERT OR IGNORE INTO topics (name, created_at) VALUES (?,?)",
            (topic, ts))
        dirty.add(str(topic))
        if prev is not None and prev["topic"] and prev["topic"] != topic:
            dirty.add(str(prev["topic"]))


def current_routes(
    conn: sqlite3.Connection,
) -> dict[str, tuple[str | None, str]]:
    """Map item_id to (topic, verdict) for the latest route per item."""
    rows = conn.execute(
        """SELECT r.item_id, r.topic, r.verdict FROM routes r
           JOIN (SELECT item_id, MAX(seq) AS m FROM routes
                 GROUP BY item_id) x
           ON r.item_id=x.item_id AND r.seq=x.m""").fetchall()
    return {r["item_id"]: (r["topic"], r["verdict"]) for r in rows}


def dirty_topics(conn: sqlite3.Connection) -> list[str]:
    """Return the dirty topic names, sorted."""
    rows = conn.execute("SELECT topic FROM dirty ORDER BY topic").fetchall()
    return [str(r["topic"]) for r in rows]


def max_route_seq(conn: sqlite3.Connection) -> int:
    """Return the highest route sequence number (0 when empty)."""
    row = conn.execute("SELECT MAX(seq) AS m FROM routes").fetchone()
    return int(row["m"]) if row and row["m"] is not None else 0


def outstanding_dispatches(conn: sqlite3.Connection) -> list[str]:
    """Item ids dispatched but not yet routed nor requeued, sorted."""
    rows = conn.execute(
        "SELECT item_id FROM dispatched ORDER BY item_id").fetchall()
    return [str(r["item_id"]) for r in rows]
```

```python
"""GitHub access: token resolution and the githubkit GraphQL seam.

This is the only module in the project that talks to the network.
"""

import subprocess
from collections.abc import Callable, Mapping

from githubkit import GitHub

GraphQLFn = Callable[[str, dict[str, object]], dict[str, object]]
"""Executes one GraphQL query with variables; returns the data object."""

Runner = Callable[..., object]
"""subprocess.run-compatible callable (injectable for tests)."""


class RateLimitExhausted(Exception):
    """GraphQL point budget dropped below the safety floor."""

    def __init__(self, remaining: int, reset_at: str | None) -> None:
        """Record the remaining budget and the reset time."""
        super().__init__(
            f"GraphQL rate limit exhausted (remaining={remaining}, "
            f"resets {reset_at})")
        self.remaining = remaining
        self.reset_at = reset_at


def resolve_token(
    env: Mapping[str, str],
    runner: Runner = subprocess.run,
) -> str:
    """Return the GitHub token from $GITHUB_TOKEN or `gh auth token`."""
    token = env.get("GITHUB_TOKEN", "").strip()
    if token:
        return token
    proc = runner(["gh", "auth", "token"], capture_output=True, text=True,
                  check=False)
    if getattr(proc, "returncode", 1) == 0:
        token = str(getattr(proc, "stdout", "")).strip()
        if token:
            return token
    raise RuntimeError("no GitHub token: set GITHUB_TOKEN or `gh auth login`")


def make_graphql(token: str) -> GraphQLFn:
    """Build a GraphQLFn backed by githubkit (typed client, retries)."""
    client = GitHub(token)

    def graphql(query: str, variables: dict[str, object]) -> dict[str, object]:
        """Execute one GraphQL request and return its data object."""
        result: dict[str, object] = client.graphql(query, variables=variables)
        return result

    return graphql
```

Note: githubkit's `graphql` call raises `githubkit.exception.GraphQLFailed`
on GraphQL errors — let it propagate; the return shape is the `data`
object, which is what fixtures model. If the installed githubkit version
exposes a different sync-graphql entry point, adapt under the GraphQL
deviation rule.

```python
"""GraphQL-batched fetch into the corpus, plus the local commit log.

Three connections are paginated (issues, pullRequests with review
threads, discussions) with one resumable cursor each; overflowing
comment lists are followed via explicit nested cursors.
"""

import json
import subprocess
from pathlib import Path
from typing import Any

from ghmem import db
from ghmem.gh import GraphQLFn, RateLimitExhausted, Runner

_COMMENTS = """
        comments(first:100, after:$cafter) {
          pageInfo { hasNextPage endCursor }
          nodes { id author { login } authorAssociation body createdAt }
        }
"""

_COMMON = """
        number title createdAt updatedAt
        author { login }
        authorAssociation
        body
        reactions { totalCount }
""" + _COMMENTS.replace(", after:$cafter", "")

_TIMELINE = """
        timelineItems(first:100, itemTypes:[CROSS_REFERENCED_EVENT]) {
          nodes { ... on CrossReferencedEvent { source { __typename
            ... on Issue { number } ... on PullRequest { number } } } }
        }
"""

ISSUES_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    issues(first:$size, after:$after,
           orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        state
""" + _COMMON + _TIMELINE + """
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""

PRS_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    pullRequests(first:$size, after:$after,
                 orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        state
        mergedBy { login }
        mergedAt
""" + _COMMON + _TIMELINE + """
        reviews(first:50) {
          nodes {
            id author { login } body createdAt
            comments(first:50) {
              nodes { id author { login } body createdAt }
            }
          }
        }
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""

DISCUSSIONS_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    discussions(first:$size, after:$after,
                orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        closed
""" + _COMMON + """
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""

# Nested continuation: one item's remaining comments past a cursor.
MORE_COMMENTS_QUERY = """
query($owner:String!, $name:String!, $number:Int!, $cafter:String) {
  repository(owner:$owner, name:$name) {
    ITEMFIELD(number:$number) {
""" + _COMMENTS + """
    }
  }
  rateLimit { remaining resetAt }
}
"""

_ITEM_FIELD = {"issue": "issue", "pr": "pullRequest",
               "discussion": "discussion"}

OWNER = "micro-editor"
NAME = "micro"

Node = dict[str, Any]


def _login(actor: object) -> str | None:
    """Extract the login from an author/actor object, if any."""
    if isinstance(actor, dict):
        login = actor.get("login")
        return str(login) if login is not None else None
    return None


def _write_comment(conn: Any, item_id: str, node: Node, kind: str) -> None:  # noqa: ANN401
    """Write one comment node under an item."""
    db.upsert_comment(
        conn, id=str(node["id"]), item_id=item_id,
        author=_login(node.get("author")), body=str(node.get("body") or ""),
        created_at=str(node["createdAt"]), kind=kind,
        assoc_hint=node.get("authorAssociation"))


def _follow_comments(conn: Any, item_id: str, kind: str, number: int,  # noqa: ANN401
                     page: Node, graphql_fn: GraphQLFn) -> None:
    """Write a comment page, then follow nested cursors to exhaustion."""
    for cnode in page.get("nodes", []):
        _write_comment(conn, item_id, cnode, "comment")
    info = page.get("pageInfo") or {}
    while info.get("hasNextPage"):
        query = MORE_COMMENTS_QUERY.replace("ITEMFIELD", _ITEM_FIELD[kind])
        data = graphql_fn(query, {
            "owner": OWNER, "name": NAME, "number": number,
            "cafter": info.get("endCursor")})
        repo: Any = data["repository"]
        page = repo[_ITEM_FIELD[kind]]["comments"]
        for cnode in page.get("nodes", []):
            _write_comment(conn, item_id, cnode, "comment")
        info = page.get("pageInfo") or {}


def _ingest_thread(conn: Any, node: Node, kind: str, item_id: str,  # noqa: ANN401, PLR0913
                   state: str, graphql_fn: GraphQLFn,
                   merged_by: str | None = None,
                   merged_at: str | None = None) -> None:
    """Shared extraction: item row, comments (nested), cross-references."""
    db.upsert_item(
        conn, id=item_id, number=int(node["number"]), kind=kind,
        title=str(node["title"]), state=state,
        author=_login(node.get("author")), body=str(node.get("body") or ""),
        created_at=str(node["createdAt"]), updated_at=str(node["updatedAt"]),
        reactions=int((node.get("reactions") or {}).get("totalCount", 0)),
        merged_by=merged_by, merged_at=merged_at,
        assoc_hint=node.get("authorAssociation"), raw=json.dumps(node))
    _follow_comments(conn, item_id, kind, int(node["number"]),
                     node.get("comments") or {}, graphql_fn)
    for t in (node.get("timelineItems") or {}).get("nodes", []):
        src = t.get("source") or {}
        if src.get("number"):
            prefix = ("pr" if src.get("__typename") == "PullRequest"
                      else "issue")
            db.add_xref(conn, item_id, f"{prefix}/{src['number']}")


def ingest_issue_node(conn: Any, node: Node,  # noqa: ANN401
                      graphql_fn: GraphQLFn) -> None:
    """Ingest one issue node."""
    _ingest_thread(conn, node, "issue", f"issue/{node['number']}",
                   str(node["state"]).lower(), graphql_fn)


def ingest_pr_node(conn: Any, node: Node,  # noqa: ANN401
                   graphql_fn: GraphQLFn) -> None:
    """Ingest one PR node, including review threads and merge fields."""
    item_id = f"pr/{node['number']}"
    _ingest_thread(conn, node, "pr", item_id, str(node["state"]).lower(),
                   graphql_fn, merged_by=_login(node.get("mergedBy")),
                   merged_at=node.get("mergedAt"))
    for review in (node.get("reviews") or {}).get("nodes", []):
        if str(review.get("body") or "").strip():
            _write_comment(conn, item_id, review, "review")
        for cnode in (review.get("comments") or {}).get("nodes", []):
            _write_comment(conn, item_id, cnode, "review-comment")


def ingest_discussion_node(conn: Any, node: Node,  # noqa: ANN401
                           graphql_fn: GraphQLFn) -> None:
    """Ingest one discussion node (closed bool becomes state)."""
    state = "closed" if node.get("closed") else "open"
    _ingest_thread(conn, node, "discussion",
                   f"discussion/{node['number']}", state, graphql_fn)


_CONNECTIONS = [
    ("issues", "cursor_issues", ISSUES_QUERY, ingest_issue_node),
    ("pullRequests", "cursor_prs", PRS_QUERY, ingest_pr_node),
    ("discussions", "cursor_discussions", DISCUSSIONS_QUERY,
     ingest_discussion_node),
]


def sync_items(conn: Any, graphql_fn: GraphQLFn, *,  # noqa: ANN401
               page_size: int = 50, min_remaining: int = 200) -> int:
    """Paginate all three connections; persist one cursor per connection.

    Raises RateLimitExhausted (cursors already saved) when the remaining
    point budget drops below min_remaining.
    """
    ingested = 0
    for field, cursor_key, query, ingest in _CONNECTIONS:
        after = db.get_meta(conn, cursor_key)
        while True:
            data = graphql_fn(query, {
                "owner": OWNER, "name": NAME, "size": page_size,
                "after": after})
            repo: Any = data["repository"]
            page = repo[field]
            for node in page["nodes"]:
                ingest(conn, node, graphql_fn)
                ingested += 1
            after = page["pageInfo"]["endCursor"]
            if after:
                db.set_meta(conn, cursor_key, after)
            limits: Any = data.get("rateLimit") or {}
            remaining = int(limits.get("remaining", min_remaining))
            if remaining < min_remaining:
                raise RateLimitExhausted(remaining, limits.get("resetAt"))
            if not page["pageInfo"]["hasNextPage"]:
                break
    return ingested


def sync_commits(conn: Any, micro_repo: Path,  # noqa: ANN401
                 runner: Runner = subprocess.run) -> int:
    """Ingest the local micro/ commit log as commit/<sha> items."""
    fmt = "%h%x09%aI%x09%an%x09%s"
    proc: Any = runner(
        ["git", "-C", str(micro_repo), "log", f"--pretty={fmt}"],
        capture_output=True, text=True, check=False)
    if proc.returncode != 0:
        raise RuntimeError(f"git log failed: {proc.stderr}")
    count = 0
    for line in str(proc.stdout).splitlines():
        if not line.strip():
            continue
        sha, date, author, subject = line.split("\t", 3)
        db.upsert_item(
            conn, id=f"commit/{sha}", number=0, kind="commit",
            title=subject, state="merged", author=author, body="",
            created_at=date, updated_at=date, reactions=0, raw="")
        count += 1
    return count
```

```python
"""Time-varying contributor standing, derived from the corpus.

standing(user, date) answers: what was this user's standing at that
moment? Derived from posting-time evidence only. GitHub's
author_association reflects fetch-time association and is NEVER
authority (it is stored separately as a display hint).

Commit authorship matches the git author name to the login
case-insensitively — a weak signal (git names are not logins); the
merge fields are the authoritative evidence.
"""

import dataclasses
import sqlite3
from typing import Literal

OWNER = "zyedidia"
ESTABLISHED_OWN_PRS = 3  # PROVISIONAL until Task 7 calibration
ESTABLISHED_COMMITS = 10  # PROVISIONAL until Task 7 calibration

Level = Literal["owner", "maintainer", "established", "newcomer"]


@dataclasses.dataclass(frozen=True)
class Standing:
    """Evidence-backed standing of one user at one moment."""

    level: Level
    merges: int
    own_merged: int
    commits: int
    maintainer_since: str | None


def standing(conn: sqlite3.Connection, user: str, date: str) -> Standing:
    """Return the standing of user strictly before date (ISO string)."""
    if user == OWNER:
        return Standing("owner", 0, 0, 0, None)
    row = conn.execute(
        "SELECT COUNT(*) AS n, MIN(merged_at) AS since FROM items "
        "WHERE kind='pr' AND merged_by=? AND author != ? AND merged_at < ?",
        (user, user, date)).fetchone()
    merges, since = int(row["n"]), row["since"]
    own = int(conn.execute(
        "SELECT COUNT(*) AS n FROM items WHERE kind='pr' AND author=? "
        "AND merged_at IS NOT NULL AND merged_at < ?",
        (user, date)).fetchone()["n"])
    commits = int(conn.execute(
        "SELECT COUNT(*) AS n FROM items WHERE kind='commit' "
        "AND lower(author)=lower(?) AND created_at < ?",
        (user, date)).fetchone()["n"])
    level: Level = "newcomer"
    if merges > 0:
        level = "maintainer"
    elif own >= ESTABLISHED_OWN_PRS or commits >= ESTABLISHED_COMMITS:
        level = "established"
    return Standing(level, merges, own, commits, since)


def annotate(conn: sqlite3.Connection, user: str | None, date: str) -> str:
    """Return the inline author annotation `user (standing evidence)`."""
    if user is None:
        return "unknown"
    s = standing(conn, user, date)
    if s.level == "owner":
        return f"{user} (owner)"
    if s.level == "maintainer":
        since = (s.maintainer_since or "")[:7]
        return (f"{user} (maintainer since {since}; "
                f"{s.merges} merges at time of comment)")
    if s.level == "established":
        return f"{user} (established contributor; {s.own_merged} PRs merged)"
    return f"{user} (newcomer)"
```

```python
"""Render one corpus thread as compact markdown (the read primitive).

Every author line carries the standing annotation at time of posting.
The fetch-time author_association hint is appended only on items
updated within RECENT_HINT_DAYS — on old items fetch-time association
says nothing about posting-time standing.
"""

import datetime
import sqlite3

from ghmem import standing

RECENT_HINT_DAYS = 90  # tunable: hint window where fetch-time ≈ posting-time


def _now_iso() -> str:
    """Current UTC time as an ISO string."""
    now = datetime.datetime.now(tz=datetime.UTC)
    return now.strftime("%Y-%m-%dT%H:%M:%SZ")


def _is_recent(updated_at: str, now: str) -> bool:
    """True when updated_at is within RECENT_HINT_DAYS of now."""
    upd = datetime.datetime.fromisoformat(updated_at.replace("Z", "+00:00"))
    ref = datetime.datetime.fromisoformat(now.replace("Z", "+00:00"))
    return (ref - upd).days <= RECENT_HINT_DAYS


def _hint(assoc: object, *, show: bool) -> str:
    """Format the assoc-hint suffix when shown and present."""
    if show and assoc:
        return f" [assoc-hint: {assoc}]"
    return ""


def render_thread(conn: sqlite3.Connection, item_id: str, *,
                  now: str | None = None) -> str:
    """Render one thread; raise KeyError when the item is absent."""
    item = conn.execute(
        "SELECT * FROM items WHERE id=?", (item_id,)).fetchone()
    if item is None:
        raise KeyError(item_id)
    ref = now or _now_iso()
    recent = _is_recent(str(item["updated_at"]), ref)
    author = standing.annotate(conn, item["author"], item["created_at"])
    lines = [
        f"# {item['kind']} #{item['number']}: {item['title']}",
        "",
        f"state: {item['state']} | author: @{author}"
        f"{_hint(item['assoc_hint'], show=recent)}"
        f" | created: {item['created_at']} | reactions: {item['reactions']}",
        "",
    ]
    if item["body"]:
        lines += [str(item["body"]), ""]
    comments = conn.execute(
        "SELECT author, body, created_at, kind, assoc_hint FROM comments "
        "WHERE item_id=? ORDER BY created_at", (item_id,)).fetchall()
    for c in comments:
        tag = "" if c["kind"] == "comment" else f" [{c['kind']}]"
        who = standing.annotate(conn, c["author"], c["created_at"])
        lines += [
            f"## @{who} ({c['created_at']}){tag}"
            f"{_hint(c['assoc_hint'], show=recent)}",
            "", str(c["body"]), "",
        ]
    xrefs = conn.execute(
        "SELECT dst_id FROM xrefs WHERE src_id=? ORDER BY dst_id",
        (item_id,)).fetchall()
    if xrefs:
        lines += ["## cross-references", ""]
        lines += [f"- {x['dst_id']}" for x in xrefs]
        lines += [""]
    return "\n".join(lines)
```

```python
"""Deterministic heat ranking over the corpus and the triage queue."""

import sqlite3

from ghmem import db

# Weights: PROVISIONAL until Task 7 calibration over the real corpus.
W_COMMENTS = 1
W_REACTIONS = 1
W_PARTICIPANTS = 2
W_XREF = 3
W_SPAN = 1


def _year(iso: str | None) -> int:
    """Year of an ISO date string (0 for None)."""
    return int(iso[:4]) if iso else 0


def signals(conn: sqlite3.Connection, item_id: str) -> dict[str, int]:
    """Compute the five heat signals for one item."""
    item = conn.execute(
        "SELECT * FROM items WHERE id=?", (item_id,)).fetchone()
    comments = conn.execute(
        "SELECT author, created_at FROM comments WHERE item_id=?",
        (item_id,)).fetchall()
    participants = {item["author"]}
    last_year = _year(item["created_at"])
    for c in comments:
        participants.add(c["author"])
        last_year = max(last_year, _year(c["created_at"]))
    xref_degree = int(conn.execute(
        "SELECT COUNT(*) AS n FROM xrefs WHERE src_id=? OR dst_id=?",
        (item_id, item_id)).fetchone()["n"])
    return {
        "comments": len(comments),
        "reactions": int(item["reactions"]),
        "participants": len(participants),
        "xref_degree": xref_degree,
        "span_years": last_year - _year(item["created_at"]),
    }


def score(sig: dict[str, int]) -> int:
    """Weighted heat score (weights provisional; see module header)."""
    return (W_COMMENTS * sig["comments"] + W_REACTIONS * sig["reactions"]
            + W_PARTICIPANTS * sig["participants"]
            + W_XREF * sig["xref_degree"] + W_SPAN * sig["span_years"])


def ranked(conn: sqlite3.Connection) -> list[tuple[str, int]]:
    """All items scored, hottest first, id-ascending on ties."""
    rows = conn.execute("SELECT id FROM items").fetchall()
    scored = [(str(r["id"]), score(signals(conn, str(r["id"]))))
              for r in rows]
    scored.sort(key=lambda t: (-t[1], t[0]))
    return scored


def pending_ids(conn: sqlite3.Connection) -> list[str]:
    """The triage queue: neither routed nor dispatched, heat order."""
    taken = set(db.current_routes(conn))
    taken.update(db.outstanding_dispatches(conn))
    return [item_id for item_id, _ in ranked(conn) if item_id not in taken]
```

```python
"""Record triage verdicts; summarize ledger coverage."""

import sqlite3
from pathlib import Path
from typing import Any

from ghmem import db, ledger


def record(ledger_path: Path, conn: sqlite3.Connection, item_id: str,
           topic: str | None = None, *, no_signal: bool = False) -> None:
    """Append one verdict to the ledger and refresh the mirror."""
    events = ledger.read(ledger_path)
    known = {e["name"] for e in events if e.get("event") == "topic"}
    known |= {e["topic"] for e in events
              if e.get("event") == "route" and e.get("topic")}
    if no_signal:
        ledger.record_no_signal(ledger_path, item_id)
    else:
        if topic is None:
            raise ValueError("route needs a topic or --no-signal")
        if topic not in known:
            ledger.record_topic(ledger_path, topic)
        ledger.record_route(ledger_path, item_id, topic)
    db.rebuild_ledger(conn, ledger.read(ledger_path))


def summary(conn: sqlite3.Connection) -> dict[str, Any]:
    """Coverage summary: verdict counts, dirty topics, sync cursors."""
    routes = db.current_routes(conn)
    routed = sum(1 for _, v in routes.values() if v == "route")
    no_signal = sum(1 for _, v in routes.values() if v == "no-signal")
    total = int(conn.execute(
        "SELECT COUNT(*) AS n FROM items").fetchone()["n"])
    dispatched = len(db.outstanding_dispatches(conn))
    return {
        "routed": routed,
        "no_signal": no_signal,
        "dispatched": dispatched,
        "pending": total - len(routes) - dispatched,
        "total": total,
        "dirty": db.dirty_topics(conn),
        "cursors": {k: db.get_meta(conn, f"cursor_{k}")
                    for k in ("issues", "prs", "discussions")},
    }


def format_status(conn: sqlite3.Connection) -> str:
    """Human-readable status block."""
    s = summary(conn)
    cursors = ", ".join(f"{k}={v or '-'}" for k, v in s["cursors"].items())
    return "\n".join([
        f"corpus items: {s['total']}",
        f"routed:       {s['routed']}",
        f"no-signal:    {s['no_signal']}",
        f"dispatched:   {s['dispatched']}",
        f"pending:      {s['pending']}",
        f"dirty topics: {', '.join(s['dirty']) or '(none)'}",
        f"sync cursors: {cursors}",
    ])
```

```python
"""The triage dispatch queue: hand out one untriaged item at a time.

Yielding an item records a dispatched ledger event so concurrent calls
hand out distinct items; a route verdict resolves the dispatch; requeue
returns crashed dispatches to the queue.

from pathlib import Path

from ghmem import db, heat, ledger


def next_item(ledger_path: Path, conn: sqlite3.Connection) -> str | None:
    """Pop the queue head (recording its dispatch); None when empty."""
    pending = heat.pending_ids(conn)
    if not pending:
        return None
    item = pending[0]
    ledger.record_dispatched(ledger_path, item)
    db.rebuild_ledger(conn, ledger.read(ledger_path))
    return item

    """Return stale dispatches to the queue; count how many there were."""
    stale = len(db.outstanding_dispatches(conn))
    ledger.record_requeue(ledger_path)
    db.rebuild_ledger(conn, ledger.read(ledger_path))
    return stale
```

```python
"""Assemble one topic's synthesis context; close out with compare-and-set.

The snapshot token pins what the synthesizer saw: the max ledger route
sequence plus the max updated_at over the topic's items. Close-out
clears the dirty flag only when the token is still current, so routes
or comments that arrive mid-synthesis leave the topic dirty for the
next run instead of being silently discarded.
"""

import sqlite3
from pathlib import Path

from ghmem import db, heat, ledger, render, standing


def items_for(conn: sqlite3.Connection, name: str) -> list[str]:
    """Item ids currently routed to name, hottest first."""
    routes = db.current_routes(conn)
    ids = [item_id for item_id, (topic, verdict) in routes.items()
           if verdict == "route" and topic == name]
    ids.sort(key=lambda i: (-heat.score(heat.signals(conn, i)), i))
    return ids


def snapshot_token(conn: sqlite3.Connection, name: str) -> str:
    """Token pinning the ledger position and the topic's item freshness."""
    seq = db.max_route_seq(conn)
    ids = items_for(conn, name)
    max_updated = ""
    if ids:
        marks = ",".join("?" for _ in ids)
        row = conn.execute(
            f"SELECT MAX(updated_at) AS m FROM items WHERE id IN ({marks})",  # noqa: S608
            ids).fetchone()
        max_updated = str(row["m"] or "")
    return f"{seq}:{max_updated}"


def context(conn: sqlite3.Connection, name: str, *,
            full_top: int = 5) -> str:
    """Markdown synthesis context for one topic, headed by its token."""
    ids = items_for(conn, name)
    if not ids:
        raise KeyError(name)
    lines = [
        f"snapshot-token: {snapshot_token(conn, name)}",
        "",
        f"# Topic: {name}",
        "",
        "Synthesize the FR / NFR / Limitations / Open questions / History "
        "topic doc. Cite issue/PR/commit numbers on every claim. Do not "
        "invent requirements with no citable maintainer behavior. Empty "
        "sections are allowed. Author lines carry standing at time of "
        "posting; requirements need maintainer-grade backing.",
        "",
        f"## Routed items ({len(ids)})",
        "",
    ]
    for item_id in ids:
        item = conn.execute(
            "SELECT title, state, author, created_at FROM items "
            "WHERE id=?", (item_id,)).fetchone()
        sc = heat.score(heat.signals(conn, item_id))
        who = standing.annotate(conn, item["author"], item["created_at"])
        lines.append(f"- {item_id} (heat {sc}, {item['state']}) "
                     f"by {who}: {item['title']}")
    lines += ["", f"## Full threads (top {min(full_top, len(ids))} by heat)",
              ""]
    for item_id in ids[:full_top]:
        lines += [render.render_thread(conn, item_id), "", "---", ""]
    return "\n".join(lines)


def close_out(ledger_path: Path, conn: sqlite3.Connection, name: str,
              token: str) -> bool:
    """Compare-and-set close-out; False leaves the topic dirty."""
    if token != snapshot_token(conn, name):
        return False
    ledger.record_synthesized(ledger_path, name)
    db.rebuild_ledger(conn, ledger.read(ledger_path))
    return True
```

```python
"""Regenerate docs/design/INDEX.md from topic-doc frontmatter.

INDEX.md is autogenerated, never agent-edited: each topic doc carries a
`description:` frontmatter field (the hook-style index line, ending with
its issue/PR citations), and this module rebuilds the index from all of
them, alphabetically by topic name for stable diffs.
"""

from pathlib import Path

HEADER = """\
# micro design memory — index

<!-- AUTOGENERATED by `ghmem index` — do not edit; edit the topic
docs' `description:` frontmatter instead. -->

One hook-style line per settled question or live debate, each linking
to a topic doc in this directory. Lines state the tension, not the
thread title, and end with the issue/PR numbers they rest on.
"""


def read_description(path: Path) -> str | None:
    """Extract the frontmatter description (folding continuations)."""
    lines = path.read_text(encoding="utf-8").splitlines()
    if not lines or lines[0].strip() != "---":
        return None
    parts: list[str] = []
    in_description = False
    for line in lines[1:]:
        if line.strip() == "---":
            break
        if line.startswith("description:"):
            parts.append(line.removeprefix("description:").strip())
            in_description = True
        elif in_description and line.startswith((" ", "\t")):
            parts.append(line.strip())
        else:
            in_description = False
    return " ".join(parts) if parts else None


def generate(design_dir: Path) -> str:
    """Return the full INDEX.md text for the design directory."""
    entries: list[str] = []
    for doc in sorted(design_dir.glob("*.md")):
        if doc.name == "INDEX.md":
            continue
        description = read_description(doc)
        if description:
            entries.append(f"- {description} → {doc.name}")
    return HEADER + "\n" + "\n".join(entries) + "\n"


def write_index(design_dir: Path) -> Path:
    """Write INDEX.md into the design directory and return its path."""
    design_dir.mkdir(parents=True, exist_ok=True)
    out = design_dir / "INDEX.md"
    out.write_text(generate(design_dir), encoding="utf-8")
    return out
```

```python
"""PreToolUse hook: deny GitHub/network access to ghmem agents.

import re
import sys

DENY = re.compile(
    r"(^|[;&|\s(])("
    r"gh|git\s+(push|pull|fetch|clone|remote)|curl|wget|ssh|scp|nc|"
    r"python[0-9.]*\s+-c.*(urllib|http|socket)|pip|uv\s+(add|pip)"

    """Read the event, emit a deny decision for matching commands."""
    event = json.load(sys.stdin)
    if event.get("tool_name") != "Bash":
        sys.exit(0)
    command = str(event.get("tool_input", {}).get("command", ""))
    if DENY.search(command):

            "hookSpecificOutput": {
                "hookEventName": "PreToolUse",
                "permissionDecision": "deny",
                "permissionDecisionReason": (
                    "ghmem agents must not reach GitHub or the network; "
                    "the only data path is `ghmem` commands over the "
                    "local corpus (uv run ghmem ...)."),
            },
        }))
        sys.exit(0)
    sys.exit(0)


if __name__ == "__main__":
    main()
```

```markdown
# ghmem

Harness for micro's reified institutional memory: it turns the GitHub
decision history into maintained topic docs under `docs/design/`. All
GitHub access and storage lives here; agents only read what `ghmem`
commands emit and write verdicts and prose.

    just green       # format, lint, types, tests

Requires a GitHub token: `$GITHUB_TOKEN` or `gh auth login`. The
`micro/` submodule must be checked out (commit log).

## Storage

- `ledger.jsonl` — append-only source of truth (verdicts, topics,
  synthesized markers). **Committed.**
- `corpus.sqlite` — regenerable fetched corpus + ledger mirror.
  **Gitignored.**

## Commands

    uv run ghmem sync                  # fetch GitHub + commit log (resumable)
    uv run ghmem show <id>             # one thread as markdown, standing-annotated
    uv run ghmem heat                  # rank the corpus by heat
    uv run ghmem triage                # next untriaged item as a packet
    uv run ghmem triage --requeue      # return stale dispatches (crash)
    uv run ghmem route <id> <topic>    # record a verdict
    uv run ghmem route <id> --no-signal
    uv run ghmem status                # coverage + dispatched + dirty
    uv run ghmem topic <name>          # synthesis context (snapshot token)
    uv run ghmem topic <name> --synthesized <token>   # close-out (CAS)
    uv run ghmem index                 # regenerate docs/design/INDEX.md

`ghmem triage` always exits 0: stdout carries the packet, or is empty
when triage is complete (`triage complete: 0 pending` on stderr).
Non-zero exit codes are reserved for actual errors.

Item ids: `issue/<n>`, `pr/<n>`, `discussion/<n>`, `commit/<sha>`.

## Standing and hints

Rendered output annotates every author with computed standing at time
of posting (owner / maintainer / established contributor / newcomer),
derived from merge authority (`merged_by`), own merged PRs, and master
commits before that date. Fetch-time `author_association` is stored as
a hint and shown only on items updated in the last `RECENT_HINT_DAYS`
(90) — it is never authority. Constants are calibrated; see
`calibration.md` before changing them.

## Agents

- `ghmem-triage` (sonnet): one item per invocation — pipe it the packet
  from `ghmem triage`; it records one `route` verdict (which resolves
  the dispatch).
- `ghmem-synthesize` (opus): one topic per invocation — it assembles
  `topic <name>`, writes `docs/design/<name>.md` with its
  `description:` frontmatter (the index line), and closes out with the
  snapshot token; close-out regenerates INDEX.md. A stale token leaves
  the topic dirty for the next run. INDEX.md is never edited by hand.

Both agents are denied GitHub/network access by a PreToolUse hook
(`hooks/deny_github.py`).

## Incremental loop

1. `uv run ghmem sync` — fetch the delta past the cursors.
2. Loop: `ghmem triage` → pipe the packet to one ghmem-triage
   invocation; stop when stdout comes back empty. After a crashed run,
   `ghmem triage --requeue` first.
3. For each dirty topic in `status`: one ghmem-synthesize invocation.

## Backfill campaign (heat-ranked, abortable)

Operated across several sessions; abortable at any point with the best
material banked.

1. **Full sync** to completion (resume on rate-limit exhaustion).
2. **Heat-ranked triage.** Work the queue from the top, one triage
   agent per id. "No-signal" is the expected majority verdict.
3. **Synthesize hot topics first.** After each triage tranche,
   synthesize the dirty topics with the most high-heat items.
   Skeleton-first is the schedule; full coverage the end state.
4. **Cold tail last**, then synthesize whatever new topics clear a
   minimum bar.
5. **Abort safely** any time: the ledger holds every verdict; a later
   sync + resume picks up where it left off.
```
