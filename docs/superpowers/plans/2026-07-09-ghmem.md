**Goal:** Build the `tools/ghmem` Python harness, two Claude Code skills, and
the `docs/memory/` artifact scaffold that reify micro's GitHub decision
history into maintained design dossiers, then prove the pipeline on the
wrapindent cluster before any bulk backfill.

**Architecture:** A 12-factor split. All deterministic work — fetch, store,
render, rank, ledger — lives in a stdlib-only Python CLI that shells out to `gh`
for GitHub access. Agents never touch the API; they read files the harness emits
and only judge (route items to topics, write prose). An append-only JSONL ledger
is the system's source of truth; a regenerable SQLite corpus mirrors it for
querying. Two skills drive the loop: triage (Sonnet, bulk classification) and
synthesize (Opus, dossier prose).

**Tech Stack:** Python 3 (3.13 present), stdlib only + `sqlite3`, `gh` CLI 2.88
for auth and GraphQL (`gh api graphql`), `unittest` for tests (no pip). Git for
the local `micro/` commit log.

## Global Constraints

- **No pip dependencies, ever.** Python 3 standard library plus the bundled
  `sqlite3` module only. Tests use `unittest`, not pytest.
- **No agent calls the GitHub API.** Only the harness shells out to `gh`;
  GraphQL goes through `gh api graphql`. Agents read harness-emitted files.
- **Ledger is the source of truth.** `tools/ghmem/ledger.jsonl` is append-only,
  committed to git, and mirrored into SQLite on every run. The corpus
  `tools/ghmem/corpus.sqlite` is regenerable and **gitignored**.
- **Deterministic tests never hit the network.** Every harness test runs against
  fixture JSON checked into `tools/ghmem/tests/fixtures/`. Injectable runner
  seams (`graphql_fn`, `runner`) replace live `gh`/`git`.
- **80-column hard-wrap for prose** in every `.md` file this plan creates or
  edits (`docs/memory/`, `README.md`, the SKILL.md files). Code and fixture JSON
  are exempt.
- **Work in the parent repo** `/Users/david/code/micro` on a branch `ghmem` cut
  from `main`. The `micro/` submodule is read-only here (only its `git log` is
  consumed); never commit inside it.
- **Shell idiom:** run commands as
  `(cd /Users/david/code/micro/tools/ghmem && <cmd>)` — a bare `cd` trips the
  environment's cwd guard, and tests import `lib` relative to that dir.
- **Commit style:** plain imperative subject, backticks around identifiers, no
  attribution trailers.
- **The seven harness commands** are `sync`, `show`, `heat`, `batch`, `route`,
  `status`, `topic` (spec Architecture §1). No others.
- **Standing is computed, never fetched.** Contributor standing (owner /
  maintainer / established contributor / newcomer) is derived from corpus
  data as of each comment's posting date. GitHub's `author_association` is
  fetch-time, not posting-time — it must NEVER be used. Rendered outputs
  annotate every author inline; agents read standing, never infer it.
- **Sequencing gate:** the wrapindent ground-truth validation (Task 6) MUST
  pass before the backfill campaign is operated. The plan's job ends at a
  verified pipeline plus a documented runbook (Task 7); the campaign itself is
  run in later sessions.
- **Deviation rule:** the live GraphQL schema field names in `sync` (Task 2) may
  differ from what this plan assumes. Because every test injects fixtures, adapt
  the query/extraction to the real schema and note the delta in the commit
  message — do not restructure the plan. Anything bigger: stop and report.

```python
"""Append-only JSONL ledger — the system's source of truth."""

import datetime
import json
import os


def _now():
    return datetime.datetime.now(datetime.timezone.utc).strftime(
        "%Y-%m-%dT%H:%M:%SZ")


def read(path):
    """Return all ledger events in file order; missing file yields []."""
    if not os.path.exists(path):
        return []
    events = []
    with open(path, "r", encoding="utf-8") as fh:
        for line in fh:
            line = line.strip()
            if line:
                events.append(json.loads(line))
    return events


def append(path, event):
    """Append one event as a JSON line, injecting a ts if absent."""
    event = dict(event)
    event.setdefault("ts", _now())
    os.makedirs(os.path.dirname(os.path.abspath(path)), exist_ok=True)
    with open(path, "a", encoding="utf-8") as fh:
        fh.write(json.dumps(event, ensure_ascii=False) + "\n")


def record_topic(path, name):
    append(path, {"event": "topic", "name": name})


def record_route(path, item, topic):
    append(path, {"event": "route", "item": item, "topic": topic})


def record_no_signal(path, item):
    append(path, {"event": "route", "item": item, "verdict": "no-signal"})


def record_fetch_failed(path, item):
    append(path, {"event": "route", "item": item, "verdict": "fetch-failed"})


def record_synthesized(path, topic):
    append(path, {"event": "synthesized", "topic": topic})
```

```python
"""SQLite corpus + ledger mirror. The JSONL ledger is source of truth;
this module rebuilds the queryable mirror from it."""

import os
import sqlite3

SCHEMA = """
CREATE TABLE IF NOT EXISTS items (
    id          TEXT PRIMARY KEY,
    number      INTEGER NOT NULL,
    kind        TEXT NOT NULL,
    title       TEXT NOT NULL,
    state       TEXT NOT NULL,
    author      TEXT,
    body        TEXT,
    created_at  TEXT NOT NULL,
    updated_at  TEXT NOT NULL,
    reactions   INTEGER NOT NULL DEFAULT 0,
    merged_by   TEXT,
    merged_at   TEXT,
    raw         TEXT
);
CREATE TABLE IF NOT EXISTS comments (
    id          TEXT PRIMARY KEY,
    item_id     TEXT NOT NULL,
    author      TEXT,
    body        TEXT,
    created_at  TEXT NOT NULL,
    kind        TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_comments_item ON comments(item_id);
CREATE TABLE IF NOT EXISTS xrefs (
    src_id      TEXT NOT NULL,
    dst_id      TEXT NOT NULL,
    PRIMARY KEY (src_id, dst_id)
);
CREATE TABLE IF NOT EXISTS meta (
    key         TEXT PRIMARY KEY,
    value       TEXT
);
CREATE TABLE IF NOT EXISTS topics (
    name        TEXT PRIMARY KEY,
    created_at  TEXT
);
CREATE TABLE IF NOT EXISTS routes (
    seq         INTEGER PRIMARY KEY AUTOINCREMENT,
    item_id     TEXT NOT NULL,
    topic       TEXT,
    verdict     TEXT NOT NULL,
    ts          TEXT
);
CREATE TABLE IF NOT EXISTS dirty (
    topic       TEXT PRIMARY KEY
);
"""


def connect(path):
    os.makedirs(os.path.dirname(os.path.abspath(path)), exist_ok=True)
    conn = sqlite3.connect(path)
    conn.row_factory = sqlite3.Row
    conn.executescript(SCHEMA)
    conn.commit()
    return conn


def upsert_item(conn, *, id, number, kind, title, state, author, body,
                created_at, updated_at, reactions, raw,
                merged_by=None, merged_at=None):
    conn.execute(
        """INSERT INTO items
           (id, number, kind, title, state, author, body, created_at,
            updated_at, reactions, merged_by, merged_at, raw)
           VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?)
           ON CONFLICT(id) DO UPDATE SET
             number=excluded.number, kind=excluded.kind, title=excluded.title,
             state=excluded.state, author=excluded.author, body=excluded.body,
             created_at=excluded.created_at, updated_at=excluded.updated_at,
             reactions=excluded.reactions, merged_by=excluded.merged_by,
             merged_at=excluded.merged_at, raw=excluded.raw""",
        (id, number, kind, title, state, author, body, created_at, updated_at,
         reactions, merged_by, merged_at, raw))
    conn.commit()


def upsert_comment(conn, *, id, item_id, author, body, created_at, kind):
    conn.execute(
        """INSERT INTO comments (id, item_id, author, body, created_at, kind)
           VALUES (?,?,?,?,?,?)
           ON CONFLICT(id) DO UPDATE SET
             item_id=excluded.item_id, author=excluded.author,
             body=excluded.body, created_at=excluded.created_at,
             kind=excluded.kind""",
        (id, item_id, author, body, created_at, kind))
    conn.commit()


def add_xref(conn, src_id, dst_id):
    conn.execute("INSERT OR IGNORE INTO xrefs (src_id, dst_id) VALUES (?,?)",
                 (src_id, dst_id))
    conn.commit()


def set_meta(conn, key, value):
    conn.execute(
        "INSERT INTO meta (key, value) VALUES (?,?) "
        "ON CONFLICT(key) DO UPDATE SET value=excluded.value", (key, value))
    conn.commit()


def get_meta(conn, key):
    row = conn.execute("SELECT value FROM meta WHERE key=?", (key,)).fetchone()
    return row["value"] if row else None


def rebuild_ledger(conn, events):
    """Wipe and replay the ledger-mirror tables from the event list."""
    conn.execute("DELETE FROM topics")
    conn.execute("DELETE FROM routes")
    conn.execute("DELETE FROM dirty")
    dirty = set()
    for e in events:
        ev = e.get("event")
        ts = e.get("ts")
        if ev == "topic":
            conn.execute(
                "INSERT OR IGNORE INTO topics (name, created_at) VALUES (?,?)",
                (e["name"], ts))
        elif ev == "route":
            item = e["item"]
            topic = e.get("topic")
            verdict = e.get("verdict", "route" if topic else "no-signal")
            prev = conn.execute(
                "SELECT topic FROM routes WHERE item_id=? "
                "ORDER BY seq DESC LIMIT 1", (item,)).fetchone()
            conn.execute(
                "INSERT INTO routes (item_id, topic, verdict, ts) "
                "VALUES (?,?,?,?)", (item, topic, verdict, ts))
            if topic:
                conn.execute(
                    "INSERT OR IGNORE INTO topics (name, created_at) "
                    "VALUES (?,?)", (topic, ts))
                dirty.add(topic)
                if prev and prev["topic"] and prev["topic"] != topic:
                    dirty.add(prev["topic"])
        elif ev == "synthesized":
            dirty.discard(e["topic"])
    for t in dirty:
        conn.execute("INSERT OR IGNORE INTO dirty (topic) VALUES (?)", (t,))
    conn.commit()


def current_routes(conn):
    rows = conn.execute(
        """SELECT r.item_id, r.topic, r.verdict FROM routes r
           JOIN (SELECT item_id, MAX(seq) AS m FROM routes GROUP BY item_id) x
           ON r.item_id=x.item_id AND r.seq=x.m""").fetchall()
    return {r["item_id"]: (r["topic"], r["verdict"]) for r in rows}


def dirty_topics(conn):
    rows = conn.execute("SELECT topic FROM dirty ORDER BY topic").fetchall()
    return [r["topic"] for r in rows]
```

```python
#!/usr/bin/env python3
"""ghmem — deterministic harness for micro's institutional memory.

All GitHub access and storage lives here; agents only read emitted files.
"""

import argparse
import os
import sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from lib import db, ledger  # noqa: E402

DEFAULT_LEDGER = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                              "ledger.jsonl")
DEFAULT_CORPUS = os.path.join(os.path.dirname(os.path.abspath(__file__)),
                              "corpus.sqlite")
DEFAULT_MICRO = os.path.normpath(
    os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "..",
                 "micro"))


def open_state(args):
    """Open the corpus and refresh its ledger mirror from the JSONL."""
    conn = db.connect(args.corpus)
    db.rebuild_ledger(conn, ledger.read(args.ledger))
    return conn


def build_parser():
    p = argparse.ArgumentParser(prog="ghmem", description=__doc__)
    p.add_argument("--ledger", default=DEFAULT_LEDGER)
    p.add_argument("--corpus", default=DEFAULT_CORPUS)
    sub = p.add_subparsers(dest="command", required=True)

    sp = sub.add_parser("sync", help="fetch GitHub + commit log into corpus")
    sp.add_argument("--micro-repo", default=DEFAULT_MICRO)

    sp = sub.add_parser("show", help="render one thread as markdown")
    sp.add_argument("id")

    sub.add_parser("heat", help="rank the corpus by heat")

    sp = sub.add_parser("batch", help="emit a triage packet")
    sp.add_argument("--pending", action="store_true")
    sp.add_argument("-n", type=int, default=20)

    sp = sub.add_parser("route", help="record a triage verdict")
    sp.add_argument("id")
    sp.add_argument("topic", nargs="?")
    sp.add_argument("--no-signal", action="store_true")

    sub.add_parser("status", help="coverage ledger summary")

    sp = sub.add_parser("topic", help="assemble a synthesis context file")
    sp.add_argument("name")
    return p


def main(argv=None):
    args = build_parser().parse_args(argv)
    # Subcommand handlers are registered by later tasks; dispatch by name.
    from lib import commands
    handler = getattr(commands, "cmd_" + args.command)
    return handler(args)


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Thin, injectable wrapper over the `gh` CLI. The only network egress."""

import json
import subprocess


class RateLimitExhausted(Exception):
    def __init__(self, remaining, reset_at):
        super().__init__(
            "GraphQL rate limit exhausted (remaining=%s, resets %s)"
            % (remaining, reset_at))
        self.remaining = remaining
        self.reset_at = reset_at


def run(args, runner=subprocess.run):
    """Run `gh <args>` and return stdout; raise RuntimeError on failure."""
    proc = runner(["gh", *args], capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError("gh %s failed: %s" % (" ".join(args), proc.stderr))
    return proc.stdout


def graphql(query, variables, runner=subprocess.run):
    """Execute a GraphQL query via `gh api graphql`; return the data object."""
    cmd = ["gh", "api", "graphql", "-f", "query=" + query]
    for key, value in variables.items():
        if isinstance(value, bool):
            cmd += ["-F", "%s=%s" % (key, "true" if value else "false")]
        elif isinstance(value, int):
            cmd += ["-F", "%s=%d" % (key, value)]
        elif value is None:
            cmd += ["-F", "%s=null" % key]
        else:
            cmd += ["-f", "%s=%s" % (key, value)]
    proc = runner(cmd, capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError("gh api graphql failed: %s" % proc.stderr)
    payload = json.loads(proc.stdout)
    if payload.get("errors"):
        raise RuntimeError("GraphQL errors: %s" % payload["errors"])
    return payload["data"]
```

### Task 2: `sync` — GraphQL fetch, cursors, resumability, commit log

The fetch pipeline: paginate three GraphQL connections — `issues`,
`pullRequests` (including review threads and review comments, which the spec
requires and Task 6's stall-rationale signal depends on), and `discussions` —
map nodes into corpus rows, keep one resumable cursor per connection, exit
cleanly on rate-limit exhaustion, and ingest the local `micro/` commit log.
GitHub's GraphQL schema returns only Issues from `repository.issues`;
PRs and discussions are separate connections. Fixture-tested end to end.
Two commits.

- Modify: `tools/ghmem/lib/commands.py` (wire `cmd_sync`)

**Interfaces:**
- Consumes: `lib.db` writers, `lib.gh.RateLimitExhausted`.
- Produces:
  - `lib.sync.ingest_issue_node(conn, node)`,
    `lib.sync.ingest_pr_node(conn, node)`,
    `lib.sync.ingest_discussion_node(conn, node)` — each writes one item row
    plus its comments and cross-references. PR ingestion also writes review
    bodies as comments with `kind="review"` and review-thread comments with
    `kind="review-comment"`, and stores `merged_by`/`merged_at` on the item
    row (the merge-authority evidence Task 3's standing derivation needs).
  - `lib.sync.sync_items(conn, graphql_fn, *, page_size=50, min_remaining=200)
    -> int` — paginates the three connections in order (issues, pullRequests,
    discussions) with `graphql_fn(query, variables) -> data`, upserts nodes,
    advances a per-connection cursor meta key (`cursor_issues`, `cursor_prs`,
    `cursor_discussions`) after each page, returns the count ingested. Raises
    `RateLimitExhausted` (after persisting the current cursor) when
    `rateLimit.remaining < min_remaining`.
  - `lib.sync.sync_commits(conn, micro_repo, runner=subprocess.run) -> int` —
    ingests `git -C <repo> log` as `commit/<sha>` items.
  - The GraphQL `data` shape the fixtures and extractor assume:
    `data.repository.<connection>.{pageInfo:{hasNextPage,endCursor},
    nodes:[...]}` where `<connection>` is `issues`, `pullRequests`, or
    `discussions`, and `data.rateLimit.{remaining,resetAt}`. Common node
    fields: `number`, `title`, `createdAt`, `updatedAt`, `author.login`,
    `body`, `reactions.totalCount`,
    `comments.nodes[].{id,author.login,body,createdAt}`. Issues and PRs add
    `state` and `timelineItems.nodes[].source.{__typename,number}`
    (cross-references); PRs add `mergedBy.login`, `mergedAt`, and
    `reviews.nodes[].{id,author.login,body,createdAt,
    comments.nodes[].{id,author.login,body,createdAt}}`; discussions add
    `closed` (bool) instead of `state`.

```python
"""sync — GraphQL-batched fetch into the corpus, plus the commit log.

Three connections are paginated: issues, pullRequests (with review
threads), discussions. The queries below target the live schema; if a
field name differs, adapt it and note the delta in the commit message
(Global Constraints: deviation rule). Tests inject fixtures and never
depend on the query text.
"""

import json
import subprocess

from lib import db, gh

_COMMON_FIELDS = """
        number title createdAt updatedAt
        author { login }
        body
        reactions { totalCount }
        comments(first:100) {
          nodes { id author { login } body createdAt }
        }
"""

_TIMELINE = """
        timelineItems(first:100, itemTypes:[CROSS_REFERENCED_EVENT]) {
          nodes { ... on CrossReferencedEvent { source { __typename
            ... on Issue { number } ... on PullRequest { number } } } }
        }
"""

ISSUES_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    issues(first:$size, after:$after,
           orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        state
""" + _COMMON_FIELDS + _TIMELINE + """
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""

PRS_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    pullRequests(first:$size, after:$after,
                 orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        state
        mergedBy { login }
        mergedAt
""" + _COMMON_FIELDS + _TIMELINE + """
        reviews(first:50) {
          nodes {
            id author { login } body createdAt
            comments(first:50) {
              nodes { id author { login } body createdAt }
            }
          }
        }
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""

DISCUSSIONS_QUERY = """
query($owner:String!, $name:String!, $size:Int!, $after:String) {
  repository(owner:$owner, name:$name) {
    discussions(first:$size, after:$after,
                orderBy:{field:UPDATED_AT, direction:ASC}) {
      pageInfo { hasNextPage endCursor }
      nodes {
        closed
""" + _COMMON_FIELDS + """
      }
    }
  }
  rateLimit { remaining resetAt }
}
"""


def _login(actor):
    return actor.get("login") if actor else None


def _ingest_thread(conn, node, kind, item_id, state,
                   merged_by=None, merged_at=None):
    """Shared extraction: item row, flat comments, cross-references."""
    db.upsert_item(
        conn, id=item_id, number=node["number"], kind=kind,
        title=node["title"], state=state,
        author=_login(node.get("author")), body=node.get("body", ""),
        created_at=node["createdAt"], updated_at=node["updatedAt"],
        reactions=node.get("reactions", {}).get("totalCount", 0),
        merged_by=merged_by, merged_at=merged_at,
        raw=json.dumps(node))
    for c in node.get("comments", {}).get("nodes", []):
        db.upsert_comment(
            conn, id=c["id"], item_id=item_id, author=_login(c.get("author")),
            body=c.get("body", ""), created_at=c["createdAt"], kind="comment")
    for t in node.get("timelineItems", {}).get("nodes", []):
        src = t.get("source") or {}
        if src.get("number"):
            prefix = ("pr" if src.get("__typename") == "PullRequest"
                      else "issue")
            db.add_xref(conn, item_id, "%s/%d" % (prefix, src["number"]))


def ingest_issue_node(conn, node):
    _ingest_thread(conn, node, "issue", "issue/%d" % node["number"],
                   node["state"].lower())


def ingest_pr_node(conn, node):
    item_id = "pr/%d" % node["number"]
    _ingest_thread(conn, node, "pr", item_id, node["state"].lower(),
                   merged_by=_login(node.get("mergedBy")),
                   merged_at=node.get("mergedAt"))
    for r in node.get("reviews", {}).get("nodes", []):
        if (r.get("body") or "").strip():
            db.upsert_comment(
                conn, id=r["id"], item_id=item_id,
                author=_login(r.get("author")), body=r["body"],
                created_at=r["createdAt"], kind="review")
        for c in r.get("comments", {}).get("nodes", []):
            db.upsert_comment(
                conn, id=c["id"], item_id=item_id,
                author=_login(c.get("author")), body=c.get("body", ""),
                created_at=c["createdAt"], kind="review-comment")


def ingest_discussion_node(conn, node):
    state = "closed" if node.get("closed") else "open"
    _ingest_thread(conn, node, "discussion",
                   "discussion/%d" % node["number"], state)


_CONNECTIONS = [
    ("issues", "cursor_issues", ISSUES_QUERY, ingest_issue_node),
    ("pullRequests", "cursor_prs", PRS_QUERY, ingest_pr_node),
    ("discussions", "cursor_discussions", DISCUSSIONS_QUERY,
     ingest_discussion_node),
]


def sync_items(conn, graphql_fn, *, page_size=50, min_remaining=200,
               owner="micro-editor", name="micro"):
    """Paginate all three connections into the corpus. Persists one
    cursor per connection after each page; raises RateLimitExhausted
    when the remaining budget drops too low."""
    ingested = 0
    for field, cursor_key, query, ingest in _CONNECTIONS:
        after = db.get_meta(conn, cursor_key)
        while True:
            data = graphql_fn(query, {
                "owner": owner, "name": name, "size": page_size,
                "after": after})
            page = data["repository"][field]
            for node in page["nodes"]:
                ingest(conn, node)
                ingested += 1
            after = page["pageInfo"]["endCursor"]
            if after:
                db.set_meta(conn, cursor_key, after)
            rl = data.get("rateLimit", {})
            remaining = rl.get("remaining", min_remaining)
            if remaining < min_remaining:
                raise gh.RateLimitExhausted(remaining, rl.get("resetAt"))
            if not page["pageInfo"]["hasNextPage"]:
                break
    return ingested


def sync_commits(conn, micro_repo, runner=subprocess.run):
    """Ingest the local micro/ commit log as commit/<sha> items."""
    fmt = "%h%x09%aI%x09%an%x09%s"
    proc = runner(["git", "-C", micro_repo, "log", "--pretty=" + fmt],
                  capture_output=True, text=True)
    if proc.returncode != 0:
        raise RuntimeError("git log failed: %s" % proc.stderr)
    count = 0
    for line in proc.stdout.splitlines():
        if not line.strip():
            continue
        sha, date, author, subject = line.split("\t", 3)
        db.upsert_item(
            conn, id="commit/%s" % sha, number=0, kind="commit",
            title=subject, state="merged", author=author, body="",
            created_at=date, updated_at=date, reactions=0, raw="")
        count += 1
    return count
```

```python
"""standing — time-varying contributor standing, derived from the corpus.

standing(user, date) answers: what was this user's standing at that
moment? Derived from posting-time evidence only. GitHub's
author_association reflects fetch-time association and is NEVER used.

Thresholds are deterministic and tunable (like the heat weights):
- owner: static (OWNER).
- maintainer: merged at least one other person's PR before `date`
  (merge authority is the hardest signal).
- established: >= ESTABLISHED_OWN_PRS own PRs merged before `date`, or
  >= ESTABLISHED_COMMITS master commits before `date`.
- newcomer: everyone else.

Commit authorship matches the git author name to the login
case-insensitively — a weak signal (git names are not logins); the
merge fields are the authoritative evidence.
"""

OWNER = "zyedidia"
ESTABLISHED_OWN_PRS = 3
ESTABLISHED_COMMITS = 10


def standing(conn, user, date):
    """Evidence-backed standing of `user` strictly before `date` (ISO)."""
    if user == OWNER:
        return {"level": "owner", "merges": 0, "own_merged": 0,
                "commits": 0, "maintainer_since": None}
    row = conn.execute(
        "SELECT COUNT(*) AS n, MIN(merged_at) AS since FROM items "
        "WHERE kind='pr' AND merged_by=? AND author != ? AND merged_at < ?",
        (user, user, date)).fetchone()
    merges, since = row["n"], row["since"]
    own = conn.execute(
        "SELECT COUNT(*) AS n FROM items WHERE kind='pr' AND author=? "
        "AND merged_at IS NOT NULL AND merged_at < ?",
        (user, date)).fetchone()["n"]
    commits = conn.execute(
        "SELECT COUNT(*) AS n FROM items WHERE kind='commit' "
        "AND lower(author)=lower(?) AND created_at < ?",
        (user, date)).fetchone()["n"]
    if merges > 0:
        level = "maintainer"
    elif own >= ESTABLISHED_OWN_PRS or commits >= ESTABLISHED_COMMITS:
        level = "established"
    else:
        level = "newcomer"
    return {"level": level, "merges": merges, "own_merged": own,
            "commits": commits, "maintainer_since": since}


def annotate(conn, user, date):
    """Inline author annotation: `user (standing evidence)`."""
    if user is None:
        return "unknown"
    s = standing(conn, user, date)
    if s["level"] == "owner":
        return "%s (owner)" % user
    if s["level"] == "maintainer":
        return "%s (maintainer since %s; %d merges at time of comment)" % (
            user, (s["maintainer_since"] or "")[:7], s["merges"])
    if s["level"] == "established":
        return "%s (established contributor; %d PRs merged)" % (
            user, s["own_merged"])
    return "%s (newcomer)" % user
```

```python
    if xrefs:

        lines += ["- %s" % x["dst_id"] for x in xrefs]
        lines += [""]
    return "\n".join(lines)
```

```python
"""heat — deterministic ranking over the corpus."""


def _year(iso):
    return int(iso[:4]) if iso else 0


def signals(conn, item_id):
    item = conn.execute("SELECT * FROM items WHERE id=?", (item_id,)).fetchone()
    comments = conn.execute(
        "SELECT author, created_at FROM comments WHERE item_id=?",
        (item_id,)).fetchall()
    participants = {item["author"]}
    last_year = _year(item["created_at"])
    for c in comments:
        participants.add(c["author"])
        last_year = max(last_year, _year(c["created_at"]))
    xref_degree = conn.execute(
        "SELECT COUNT(*) AS n FROM xrefs WHERE src_id=? OR dst_id=?",
        (item_id, item_id)).fetchone()["n"]
    return {
        "comments": len(comments),
        "reactions": item["reactions"],
        "participants": len(participants),
        "xref_degree": xref_degree,
        "span_years": last_year - _year(item["created_at"]),
    }


def score(sig):
    return (sig["comments"] + sig["reactions"] + 2 * sig["participants"]
            + 3 * sig["xref_degree"] + sig["span_years"])


def ranked(conn):
    rows = conn.execute("SELECT id FROM items").fetchall()
    scored = [(r["id"], score(signals(conn, r["id"]))) for r in rows]
    scored.sort(key=lambda t: (-t[1], t[0]))
    return scored
```

```python
from lib import db, heat, standing


def pending_ids(conn):
    routed = db.current_routes(conn)
    return [item_id for item_id, _ in heat.ranked(conn) if item_id not in routed]


def packet(conn, n):
    ids = pending_ids(conn)[:n]
    lines = ["# Triage packet (%d items)" % len(ids), "",
             "For each item call `ghmem route <id> <topic>` or "
             "`ghmem route <id> --no-signal`.", ""]
    for item_id in ids:
        item = conn.execute(
            "SELECT * FROM items WHERE id=?", (item_id,)).fetchone()
        sc = heat.score(heat.signals(conn, item_id))
        ncomments = conn.execute(
            "SELECT COUNT(*) AS n FROM comments WHERE item_id=?",
            (item_id,)).fetchone()["n"]
        body = (item["body"] or "").strip().replace("\n", " ")
        if len(body) > 200:
            body = body[:200] + "..."
        who = standing.annotate(conn, item["author"], item["created_at"])
        lines += ["## %s — %s" % (item_id, item["title"]),
                  "author: %s | state: %s | heat: %d | comments: %d"
                  % (who, item["state"], sc, ncomments),
                  "", body, ""]
    return "\n".join(lines)
```

```python
"""route — record triage verdicts; status — summarize coverage."""

from lib import db, ledger


def record(ledger_path, conn, item_id, topic=None, no_signal=False):
    events = ledger.read(ledger_path)
    known = {e["name"] for e in events if e.get("event") == "topic"}
    known |= {e["topic"] for e in events
              if e.get("event") == "route" and e.get("topic")}
    if no_signal:
        ledger.record_no_signal(ledger_path, item_id)
    else:
        if topic and topic not in known:
            ledger.record_topic(ledger_path, topic)
        ledger.record_route(ledger_path, item_id, topic)
    db.rebuild_ledger(conn, ledger.read(ledger_path))


def summary(conn):
    routes = db.current_routes(conn)
    routed = sum(1 for t, v in routes.values() if v == "route")
    no_signal = sum(1 for t, v in routes.values() if v == "no-signal")
    total = conn.execute("SELECT COUNT(*) AS n FROM items").fetchone()["n"]
    return {
        "routed": routed,
        "no_signal": no_signal,
        "pending": total - len(routes),
        "total": total,
        "dirty": db.dirty_topics(conn),
        "cursors": {k: db.get_meta(conn, "cursor_" + k)
                    for k in ("issues", "prs", "discussions")},
    }


def format_status(conn):
    s = summary(conn)
    cursors = ", ".join("%s=%s" % (k, v or "-")
                        for k, v in s["cursors"].items())
    return "\n".join([
        "corpus items: %d" % s["total"],
        "routed:       %d" % s["routed"],
        "no-signal:    %d" % s["no_signal"],
        "pending:      %d" % s["pending"],
        "dirty topics: %s" % (", ".join(s["dirty"]) or "(none)"),
        "sync cursors: %s" % cursors,
    ])
```

```python
"""topic — assemble one topic's synthesis context for an Opus session."""

from lib import db, heat, render, standing


def items_for(conn, name):
    routes = db.current_routes(conn)
    ids = [item_id for item_id, (topic, verdict) in routes.items()
           if verdict == "route" and topic == name]
    ids.sort(key=lambda i: (-heat.score(heat.signals(conn, i)), i))
    return ids


def context(conn, name, *, full_top=5):
    ids = items_for(conn, name)
    if not ids:
        raise KeyError(name)
    lines = ["# Topic: %s" % name, "",
             "Synthesize the FR / NFR / Limitations / Open questions / History "
             "dossier for this topic. Cite issue/PR/commit numbers on every "
             "claim. Do not invent requirements with no citable maintainer "
             "behavior. Empty sections are allowed. Author lines carry "
             "standing at time of posting; requirements need maintainer-grade "
             "backing.", "",
             "## Routed items (%d)" % len(ids), ""]
    for item_id in ids:
        item = conn.execute(
            "SELECT title, state, author, created_at FROM items WHERE id=?",
            (item_id,)).fetchone()
        sc = heat.score(heat.signals(conn, item_id))
        who = standing.annotate(conn, item["author"], item["created_at"])
        lines.append("- %s (heat %d, %s) by %s: %s"
                     % (item_id, sc, item["state"], who, item["title"]))
    lines += ["", "## Full threads (top %d by heat)" % min(full_top, len(ids)),
              ""]
    for item_id in ids[:full_top]:
        lines += [render.render_thread(conn, item_id), "", "---", ""]
    return "\n".join(lines)
```

```markdown
# ghmem triage

**Model:** run this skill on Sonnet (bulk classification). The operator launches
it as a Sonnet session or subagent.

## What triage decides

For each item in a batch packet, choose exactly one:

- **Route to a topic** — the item carries a design decision, a rejected
  approach, or a live debate that belongs in a named dossier. Call
  `ghmem route <id> <topic>`.
- **No-signal** — the item is a bug report, support question, duplicate, or
  chatter with no design rationale. Call `ghmem route <id> --no-signal`. This
  is the expected verdict for most items: literature shows only ~1/3 of closed
  PRs cleanly encode a decision. Do not manufacture a topic to avoid it.

Author lines carry standing at time of posting (owner / maintainer /
established contributor / newcomer); read the annotations, never infer
standing yourself. Maintainer-engaged items are stronger topic candidates —
a maintainer stating a position or rejecting an approach is exactly the
signal dossiers exist to capture.

## Loop

1. Emit a packet: `python3 tools/ghmem/ghmem.py batch --pending -n 25`.
2. For each item, read its digest. When the digest is ambiguous, pull the full
   thread: `python3 tools/ghmem/ghmem.py show <id>`.
3. Decide route-or-no-signal. Prefer an existing topic; check the current list
   in `python3 tools/ghmem/ghmem.py status`. Propose a **new** topic only when
   the item's decision axis is genuinely not covered — routing to a new topic
   name creates it automatically.
4. Record the verdict with `ghmem route`.
5. Repeat until the packet is exhausted, then emit the next packet. Stop when
   `status` shows no pending items or the operator ends the window.

## Topic-naming rules

- One topic per **decision axis**, not per thread. `wrapindent` and
  `softwrap-geometry` are axes; "PR #3107" is not.
- Reuse a topic across every item that touches the same axis, however many
  years apart.
- Norm topics (cross-cutting philosophy, e.g. `options-parsimony`) are
  legitimate and often all-NFR.

## Guardrails

- Never call `ghmem sync` or any `gh` command — triage only reads harness
  output and writes verdicts.
- A verdict is reversible: re-running `ghmem route <id> <newtopic>` supersedes
  the old one and marks both topics dirty. Prefer getting it right, but do not
  agonize — synthesis is where prose quality is enforced.
```

```markdown
# ghmem synthesize

**Model:** run this skill on Opus (prose quality). The operator launches it as
an Opus session or subagent, one topic at a time.

## Input

`python3 tools/ghmem/ghmem.py topic <name>` — a context file with every routed
item's digest and the full text of the high-heat ones. The update unit is one
topic; incremental runs touch only dirty topics (`ghmem status` lists them).

## Output: the dossier

Write `docs/memory/dossiers/<name>.md` with these sections, in order:

- **FR** — functional requirements the project has demonstrably enforced,
  numbered (`<name>.FR1`) for stable citation. Descriptive, not aspirational.
- **NFR** — non-functional requirements / norms, numbered (`<name>.NFR1`).
- **Limitations** — rejected approaches and won't-happens, with the rejection
  rationale. Rejected and stalled PRs are first-class evidence here.
- **Open questions** — live, unresolved debates and their current front line
  (who holds what position, where it stalled).
- **History** — a compressed chronological debate digest the other sections
  cite into.

## Hard rules

- **Every FR / NFR / Limitation carries a citation** to an issue, PR, or commit
  number. A requirement with no citable maintainer behavior behind it does not
  get written — this is the guard against hallucinated rationale.
- **Standing rules.** Author lines in the context carry standing at time of
  posting; read them, never infer standing yourself.
  - FR / NFR / Limitation entries require **maintainer-grade backing**: a
    statement by someone with owner or maintainer standing *at that time*, or
    actual merge/reject behavior. A user chorus — however loud — is demand
    evidence, never policy.
  - **History and Open questions attribute positions with standing.** A live
    debate's front line is where the people with merge power currently
    stand; say who holds what position and what their standing is.
- **Empty sections are allowed.** Norm topics are legitimately all-NFR. Do not
  invent filler to populate a section.
- Reload the full topic context each run (no delta bookkeeping) and rewrite the
  dossier from it.

## INDEX.md

Add or update one hook-style line per settled question or live debate this
dossier covers. Write the tension, not the title: "wrapindent stalled:
option-count aversion + indent-vs-wrap axis confusion" links into the dossier;
"PR #3107 discussion" does not. Every line cites numbers.

## Close out

After writing the dossier and INDEX.md lines, mark the topic clean:
`python3 tools/ghmem/ghmem.py topic <name> --synthesized`. `ghmem status`
should then drop it from the dirty list. Never call `gh` or `ghmem sync`.
```

```markdown
# ghmem

Deterministic harness that reifies micro's GitHub decision history into
maintained dossiers under `docs/memory/`. All GitHub access and storage lives
here; agents only read files this tool emits and write verdicts and prose.

## Requirements

- Python 3 (standard library + `sqlite3` only — no pip packages).
- `gh` CLI, authenticated (`gh auth status`).
- The `micro/` submodule checked out (for the commit log).

## Storage

- `ledger.jsonl` — append-only source of truth (routing verdicts, topic list,
  synthesized markers). **Committed.**
- `corpus.sqlite` — regenerable mirror + fetched corpus. **Gitignored.**

## Commands

    python3 ghmem.py sync                 # fetch GitHub + commit log (resumable)
    python3 ghmem.py show <id>            # render one thread as markdown
    python3 ghmem.py heat                 # rank the corpus by heat
    python3 ghmem.py batch --pending -n K # emit a triage packet
    python3 ghmem.py route <id> <topic>   # record a routing verdict
    python3 ghmem.py route <id> --no-signal
    python3 ghmem.py status               # coverage summary + dirty topics
    python3 ghmem.py topic <name>         # assemble synthesis context
    python3 ghmem.py topic <name> --synthesized   # mark a dossier clean

Item ids: `issue/<n>`, `pr/<n>`, `discussion/<n>`, `commit/<sha>`.

## Standing

`show`, `batch`, and `topic` annotate every author with their standing at
time of posting (owner / maintainer / established contributor / newcomer),
derived from corpus data only: merge authority (`merged_by`), own merged
PRs, and master commits before that date. GitHub's `author_association` is
never used — it is fetch-time, not posting-time. Thresholds are tunable
constants in `lib/standing.py`.

## Incremental loop

1. `ghmem sync` — fetch the delta past the per-connection cursors.
2. Triage the delta (ghmem-triage skill, Sonnet): `batch --pending` →
   `route ...` until `status` shows no pending items.
3. Synthesize dirty topics (ghmem-synthesize skill, Opus): for each name in
   `status`' dirty list, run the skill on `topic <name>`, then
   `topic <name> --synthesized`.

## Backfill campaign (heat-ranked, abortable)

The one-time full-coverage backfill is operated across several sessions. It is
abortable at any point with the best material banked — hottest topics first,
the cold tail batch-triaged last.

1. **Full metadata sync.** Run `ghmem sync` to completion (resume on rate-limit
   exhaustion; the cursors are persisted). Confirm with `ghmem status`.
2. **Heat-ranked triage.** In each Sonnet window, `ghmem batch --pending -n 25`
   works the hottest untriaged items first (the packet is already heat-ordered).
   "No-signal" is the expected verdict for most items. Repeat across windows.
3. **Synthesize hot topics first.** After each triage pass, synthesize the
   dirty topics with the most routed high-heat items. Skeleton-first is the
   schedule; full coverage is the end state.
4. **Cold tail last.** Once hot topics have dossiers, batch-triage the remaining
   low-heat items and synthesize whatever new topics clear a minimum bar.
5. **Abort safely** any time: the ledger holds every verdict, dirty flags
   survive, and a later `ghmem sync` + resume picks up where it left off.

Budget note (measured 2026-07-09): whole corpus ≈ 3–4M tokens raw; one-pass
Sonnet triage ≈ 5M input tokens; Opus synthesis ≈ 3–6M more. Fits a Max5 plan
across a few 5-hour windows.

## Do not

- Do not run the backfill before the wrapindent ground-truth validation passes
  (`docs/superpowers/validation/2026-07-09-ghmem-wrapindent.md`).
- Do not let any agent call `gh` or the GitHub API — only this harness does.
- Do not commit `corpus.sqlite`; do commit `ledger.jsonl`.

## Tests

    cd tools/ghmem && python3 -m unittest discover -s tests

All tests are deterministic and offline (fixtures under `tests/fixtures/`).
```
